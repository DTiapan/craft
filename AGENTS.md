# Craft — Agent Instructions

This repository **is** a skills library. When working here:

1. Read [README.md](README.md) for layout conventions.
2. Each skill lives under `skills/<name>/SKILL.md` with YAML frontmatter (`name`, `description`).
3. New skills must include: purpose, triggers, workflow steps, verification gates, anti-patterns, and templates.
4. Do not duplicate Cursor built-ins in `~/.cursor/skills-cursor/`.

When the user asks to add or refine a skill, read [skills/using-craft/SKILL.md](skills/using-craft/SKILL.md) first.
