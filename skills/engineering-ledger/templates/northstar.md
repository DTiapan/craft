## 3. Market Validation Scorecard (Threshold: $\ge 7/10$ to Build)

Rate the opportunity across the following 5 dimensions (0–2 points each):

| Dimension | Question | Score (0–2) | Evidence / Justification |
|---|---|---|---|
| **1. Urgent Pain** | Is this an acute, frequent problem that users actively complain about or spend money/time trying to solve? *(0 = minor annoyance, 1 = moderate friction, 2 = acute hair-on-fire pain)* | /2 | |
| **2. Willingness to Pay** | Is there clear budget, economic ROI, or demonstrated willingness to pay/adopt? *(0 = expects free/trivial, 1 = probable budget, 2 = obvious hard ROI)* | /2 | |
| **3. Alternative Weakness** | Are existing incumbents or workarounds slow, brittle, overpriced, or inadequate? *(0 = good-enough alternatives exist, 1 = moderate dissatisfaction, 2 = severe gap in market)* | /2 | |
| **4. Technical Feasibility** | Can we build a defensible, high-reliability solution with current tech without research miracles? *(0 = speculative/unlikely, 1 = complex with risks, 2 = clear high-conviction path)* | /2 | |
| **5. Strategic Moat / Distribution** | Do we have an unfair advantage in distribution, workflow lock-in, data gravity, or evaluation benchmark dominance? *(0 = commodity, 1 = moderate moat, 2 = strong compounding advantage)* | /2 | |
| **TOTAL SCORE** | **Sum of all 5 dimensions** | **/10** | |

### Gate Decision
- [ ] **PASS (Score $\ge 7$)**: High-conviction greenlight. Proceed to `Spec` and `Plan`.
- [ ] **HOLD (Score $< 7$)**: **BUILD IS BLOCKED**. Re-interview users, pivot scope, or abandon before writing code.
